## PRE-001 — AI Blueprint pattern reference

Date accessed: 2026-09-17  
Source: https://github.com/aiblueprinthq/ai-blueprint  
Source type: Maintainer repository and documentation  
Claim supported: A reusable, file-backed workflow can keep specifications, findings, review evidence, and history inside each project and make them readable by multiple AI tools.

External finding: AI Blueprint describes itself as a file-backed, spec-driven workflow layer installed around an existing application. It separates planning inputs, current work, findings, reviews, and history, and supports multiple file-aware agents.

Limitations: It is primarily a software coding workflow. Its feature lifecycle, commands, dashboard, runtime assumptions, and implementation gates are not automatically suitable for universal idea, service, business, or non-software development.

Project interpretation: Reuse the principles of project-local durable state, cross-agent instructions, narrow active context, explicit approval, and evidence-backed completion. Do not copy its coding-specific lifecycle as the universal method.

Confidence: High for the observed repository pattern; low until broader research shows how it generalizes.
