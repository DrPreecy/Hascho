# Open questions

Only questions whose answers can materially change the result belong here.

## Before Gate R0

- Is the proposed research breadth proportional, or should any domain be reduced?
- What evidence and comparison criteria are sufficient to choose an architecture?
- Which visual artifacts must be reviewable before architecture approval?
- How should work be split into reviewable increments without turning the process into chat-by-chat micromanagement?

## Later gates

- What is the smallest truly universal core?
- Which module activation rules are understandable and testable?
- How should a project-local workbench receive updates to its universal base without overwriting local decisions and state?
- What state must be machine-readable, human-readable, or both?
- Which actions require human approval, and which can be safely automated?
- How should voice capture preserve raw input, transcript, interpretation, and confirmation?
- How should stale evidence and invalidated decisions propagate?
- When is a specialized agent justified over a reusable skill?
- What is the realistic MVP after the method is approved?

Do not ask the Project Owner questions that reliable research can answer.
