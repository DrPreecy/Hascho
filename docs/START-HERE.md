# Start here

## What we are building

We are designing a universal workbench for taking a thought through exploration, research, decisions, validation, planning, building, launch, operation, learning, scaling, pivoting, pausing, or orderly termination.

The future workbench is project-local:

- A new project receives its own copy or installation.
- Its state stays with that project.
- It adapts to project type and risk.
- A stable base preserves common language, evidence discipline, decision governance, continuity, and reusable workflows.
- It is not one large application where every unrelated project is managed together.

## What this repository is today

This is the first project: the workbench is being designed using its own emerging principles.

The repository currently stores:

- the authoritative brief;
- operating rules for AI assistance;
- preliminary architecture direction;
- the plan that still needs human approval;
- decisions, open questions, and research provenance.

It does not yet contain a final method, product architecture, software architecture, or application.

## Do not do yet

- Do not implement software.
- Do not select a tech stack.
- Do not finalize the entity model.
- Do not assume every project becomes a startup or software product.
- Do not turn the process into a fixed phase checklist.
- Do not create a central multi-project product.
- Do not create many agents before capabilities and boundaries are understood.
