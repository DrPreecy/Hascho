# Provisional architecture direction

## Direction selected in the preparatory conversation

Adaptive Project Workbench, with visual orientation from a Control Room.

## Intended meaning

- The workbench adapts to the current project rather than forcing a fixed path.
- A small universal core maintains continuity and decision discipline.
- Optional modules activate only when justified.
- A visual Control Room helps the user understand current context and next action.
- Specialized visualizations support specific cognitive tasks.
- The canonical state remains portable and independent of one AI provider or interface.
- Each project has its own workbench instance; this is not a centralized multi-project application.

## What is not yet decided

- final lifecycle, loops, or gates;
- final work modes;
- final object or storage model;
- packaging and installation mechanism;
- UI architecture;
- technology stack;
- number of agents or skills;
- local, hosted, or hybrid deployment;
- MVP scope.

Research and architecture comparison may refine or overturn any non-approved detail.
